# Walkthrough: Skill de testing clínico de usabilidad

## Contexto

Se creó una skill estable para repetir auditorías exploratorias de usabilidad clínica sobre Systia.ar / Denta Cloud. El objetivo es simular usuarios reales de clínica que ingresan por primera vez al sistema y cargan pacientes, historia clínica, odontograma, agenda, finanzas, prótesis y configuración.

## Artefacto creado

- `.agents/skills/clinical-usability-testing/SKILL.md`
- `.agents/skills/clinical-usability-testing/references/test-scenarios.md`
- `.agents/skills/clinical-usability-testing/references/module-checklist.md`
- `.agents/skills/clinical-usability-testing/references/report-template.md`

## Uso esperado

Activar la skill cuando el Super Admin solicite testing como secretaria, médico, odontólogo, laboratorio o usuario nuevo, especialmente antes de demos comerciales, venta o salida a producción.

## Controles cubiertos

- Escenarios de pacientes ficticios realistas.
- Checklist por módulo.
- Evaluación de textos, títulos, validaciones, fricción, diseño y responsividad.
- Priorización P0/P1/P2/P3.
- Plantilla de estado de situación para decidir correcciones.
